# 纪录片采访感病毒切片 V2 制作记录

## 核心升级

- 从固定双人分屏生成左人物近景、右人物近景和双人全景。
- 根据说话人时间轴每 3–6 秒切换有效镜头，并插入 0.7 秒听者反应镜头。
- 使用同源直播画面的模糊扩展背景填满竖屏，取消纯黑大面积字幕区。
- 字幕移入画面，增加说话人色彩标识、关键词标签、圆角半透明底和两行限制。
- 本地生成低强度纪录片氛围音，在开场、5 秒承诺与段落交接加入低频提示。
- 保留第一版，V2 独立输出到 `exports-v2/`。

## 镜头分布

- 成片 1：24 镜头；4 双人、17 左人物、3 右人物反应。
- 成片 2：45 镜头；6 双人、20 左人物、19 右人物。
- 成片 3：44 镜头；6 双人、6 左人物反应、32 右人物。
