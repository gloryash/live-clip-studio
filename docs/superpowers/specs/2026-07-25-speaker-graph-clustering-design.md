# 声纹图聚类第二轮实验设计

日期：2026-07-25

## 目的

现有留一法诊断证明三种 embedding 对四位说话人的长字幕均达到约99%分类准确率，因此第二轮只改“自动发现中心”的算法，不重新提取声纹，也不在推理时读取人工标签。

当前视频已因反复诊断成为开发集。本轮结果只用于验证机制，不能作为未来产品的无偏测试成绩。

## 预先冻结的三条路线

### A：NME谱聚类

对全部长字幕 embedding 构建稀疏余弦相似度图，扫描固定邻居数 `5/10/20/40/80`，用 normalized maximum eigengap 同时选择图密度和人数，再以谱向量做确定性 KMeans。

优点：是成熟 diarization 思路，人数来自图谱而非 silhouette。缺点：大量重复样本仍可能主导图结构。

### B：声学轮次 + NME谱聚类

用相邻字幕 embedding 的两成分 Gaussian Mixture 自动区分“同一声纹连续段”和“说话人切换”，先把连续字幕聚合为轮次中心，再执行路线A。

优点：减少音素和短句波动。缺点：相邻相似度的两个分布可能重叠。

### C：多尺度微型簇 + NME谱聚类（推荐）

复用5/10/20分钟局部过聚类，把所有微型簇中心等权放入图中执行路线A；最后使用全局中心给每条长字幕重新分配标签。

优点：减弱1649条多数类对29/31条少数类的数量压制。缺点：同一声学子簇会跨尺度重复，需要最终中心合并。

## 公平性与防泄漏

- 三条路线及参数在评分前一次性冻结并批量运行。
- 推理模块不接受人数、标签或评分文件参数。
- 只使用现有 `.npz` embedding 和 `segments.json`。
- 三条路线全部保留，不根据分数删除失败路线。
- 评分只发生在三个预测文件写完之后。
- 本轮评分后不修改参数并重跑当前视频。

## 输出与验收

每个 embedding 模型输出三条路线的：自动人数、逐字幕预测、UNKNOWN、内部 eigengap 证据和运行时间。评分输出 accuracy、Macro-F1、每人 precision/recall/F1、长短字幕。

机制验证关注：

1. 自动人数是否更接近4。
2. 说话人3、4是否同时获得非零且明显的召回。
3. Macro-F1是否超过第一轮动态注册的67.65%。
4. 是否接近或超过旧ECAPA 20分钟基线的94.94% accuracy、77.61% Macro-F1。

如果仅对当前开发视频变好，也不能宣称泛化成功；下一步必须换全新视频冻结测试。
