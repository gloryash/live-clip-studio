# 字幕快捷软删除设计

## 目标

在快捷标注模式中，用户按 `D` 即可删除当前误识别字幕，并自动继续下一条字幕的标注。删除结果必须跨刷新保留，且不能污染说话人训练集。

## 交互

- 仅当快捷标注模式开启、字幕面板可见且焦点不在输入控件内时响应 `D`。
- 按下 `D` 后，当前字幕立即从可见序列移除。
- 系统自动激活删除前序列中的下一条字幕，并把视频定位到该条的开始时间。
- 左右方向键和空格键行为保持不变。
- 删除失败时保留当前字幕并显示现有错误提示。

## 数据与接口

- 删除采用持久化软删除，不修改 `speaker-turns.json`。
- 后端在任务的 `transcript/` 目录单独保存已删除字幕 ID。
- 删除接口校验任务、字幕状态及字幕 ID，重复删除保持幂等。
- 标注状态接口同时返回已删除 ID、有效字幕总数和有效已标注数。
- 已删除字幕不计入“待标注总数”，也不参与训练集完整性校验和 JSONL 导出。
- 已有人工说话人标签继续保留，以便未来恢复字幕时复用，但不会被导出。

## 验收

| 需求 | 验证方式 | 通过标准 |
| --- | --- | --- |
| `D` 删除并前进 | Agent Browser | 当前卡片消失，下一条激活，视频轴同步 |
| 删除跨刷新保留 | API + Agent Browser | 刷新后该字幕仍不出现 |
| 删除不污染训练集 | API 测试 | 完整性计算和 JSONL 均排除已删除字幕 |
| 快捷键不误触 | 前端契约测试 | 非快捷模式、输入控件焦点下不处理 `D` |
| 历史标注安全 | API/文件检查 | 现有人工标签数量与内容不被覆盖 |

## 非目标

- 本次不增加恢复已删除字幕的 UI。
- 本次不修改 Whisper 原始识别结果，也不重新运行转写、说话人识别或关键帧任务。
