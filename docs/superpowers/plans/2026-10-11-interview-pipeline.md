# 访谈切片流水线执行计划

用户目标：AI 仅阅读已标注的文本与说话人，按固定协议提出剪辑决策；普通后端负责校验、镜头编排、剪切、字幕动效、音效、封面和质检。更换直播后无需再让命令行 AI 识别全流程或改渲染代码。

## 已确认与待验证的假设

- 运行环境沿用本机 macOS、Python 3.12、FFmpeg；输出 1080×1920/30fps/H.264/AAC，可供视频号人工发布。浏览器不参与核心链路；部署/网页需求已通过提问工具征询，未答复时按本地后端实现。
- 输入从项目任务目录导出 `live-clip-studio.ai-transcript` v1，或直接使用同格式标注 JSON。人工说话人标签优先于预测，删除字幕不再入选；UNKNOWN 使用双人镜头，禁止偷偷继承上一位说话人。
- 凭证从 CC Switch 只读加载到当前进程环境，显式环境变量优先。固定入口 `https://api.relayrouter.ai/v1`，固定模型请求 `gpt-6.1-sol`；不更改 CC Switch 当前配置，不保存密钥到项目。
- CC Switch 明确使用 Responses API。无 Context7 工具，OpenAI 文档页面访问受限，已读取 OpenAI 官方 SDK 的 Responses 请求类型作为格式依据；relayrouter 对模型、认证、JSON Schema 的支持仍须真实探针确认，不擅自降级模型。
- 固定模板采用冷开场 3–7 秒、正文单主题、最终时长 60–180 秒、标题/悬念/互动卡两行、章节卡/要点/金句。AI 只输出整数句段 ID，不输出时间、裁切坐标、程序或 FFmpeg 参数。
- 双人左右分屏与主画面加小窗用每场配置的像素矩形表达，同一渲染器处理；布局人工设置一次，不假设所有视频尺寸及人物位置相同。选题精彩与否、标签身份和最终发布仍需人审。
- Whisper 的原词时间并非准确音素对齐。优先保留整句边界、气口寻找不得越过语音，缺词时间给出警示，成片回听差异定位到输出时间/源时间/句段，不能把文本相似度当成完整试听。

## 执行阶段与标准产出

| 阶段 | 工作 | 标准产出 | 验收门槛 |
| --- | --- | --- | --- |
| P1 契约与输入 | 固定 JSON Schema、布局配置、输入适配、质量摘要 | schema、两种布局示例、标准字幕 JSON、紧凑编号稿、输入报告 | 非连续 ID 正确、人工覆盖/删除有效、时间有界、布局矩形合法 |
| P2 模型接入 | CC Switch 凭证、Responses API 探针、分窗选题后细化、校验失败重试 | API 探针安全记录、固定提示词、逐次请求/响应与用量、候选配置 | 请求模型确为 gpt-6.1-sol；不泄漏密钥；超时/截断/非 JSON 可定位；最多有界重试 |
| P3 校验与时间线 | Schema 和业务校验、去重/时长/冷开场/挂点、确定性镜头 | validation.json、逐源句与输出时间线、shots/cues | 虚构 ID、重复正文、越界卡片、不合时长拒绝；无 AI 时间；镜头覆盖无缝 |
| P4 通用渲染 | 复用已有字幕图形与音效，配置驱动裁切和人物镜头 | MP4、SRT、封面、FFmpeg 日志、渲染报告 | 两种布局能真实渲染，未知人物双人，完整解码，输出竖屏，时长与计划一致 |
| P5 自动质检与编排 | 单命令串联、阶段状态和失败日志、重跑缓存、回听/抽帧/发布稿 | run.json、events.jsonl、qa/*.json、抽帧、publish.md | 失败写明阶段/错误/日志；输入改变不沿用旧配置；无需 AI 可重渲染；QA 异常退出且保留文件 |
| P6 独立直播验收 | 使用 GEO 直播，全场文本选题，至少 2 条完整切片 | 独立直播 exports、真实模型用量、完整 QA 证据与报告 | 不复用 fb16 选句；每条 60–180 秒；1080×1920；音画差≤0.1秒；完整解码；Whisper 回听与关键帧检查 |
| P7 交付 | 独立代码审查、修复与回归、更新说明 | 操作说明、计划完成状态、QA 报告 | 重要审查问题解决；现有回归测试通过；明确已验证能力和人工审核项 |

## 关键组件单独测验

先写行为测试再实现关键组件：输入和说话人优先级、错误 ID/卡片/重复/时长验证、API 回包与失败重试、布局边界、镜头无缝覆盖与最大时长、阶段失败状态、旧产物缓存失效。慢依赖在 HTTP 传输边界模拟，不能以模拟渲染成功替代真实 FFmpeg 验收。先用短真实素材测两种布局，再渲染独立直播完整片。

## 故障定位点

| 错误点 | 检测方式 | 保留证据与处理 |
| --- | --- | --- |
| 源视频/音轨/转写缺失或无效 | preflight + ffprobe + 输入校验 | input-report.json；阻止外部调用和渲染 |
| 标注未知/词时间回退 | 标准字幕质量摘要 | 提示审阅；UNKNOWN 双人，整句时间回退 |
| 认证/模型/网络/流式协议失败 | 独立 API 探针与 HTTP 状态 | 安全错误码和请求 ID，不记录 token，不自动换模型 |
| 模型虚构编号/格式错误/内容超长 | JSON Schema + 业务校验 | 保存原输出/错误，反馈重试一次，仍错则失败 |
| 输入很长/选题重复 | 有界文本分窗、全场覆盖、候选去重 | windows/主题来源 ID；控制调用次数与输出 token |
| 时间戳不准/吃字 | 整句边界、源时间线、Whisper 反向转写 | 差异及距剪切点位置；保留 FAIL/REVIEW，不伪装通过 |
| 裁切出界/画面变形/人物错误 | 源尺寸对照布局、两种布局小样、抽帧 | 配置错误直接拒绝；渲染滤镜保持比例 |
| FFmpeg 崩溃/中断/磁盘问题 | 返回码、临时输出、阶段状态 | 每片日志，成功后原子替换输出；保留重跑入口 |
| 成片缺音轨/音画不同步/黑帧 | ffprobe、完整 decode、抽帧、响度检测 | qa 技术报告；阶段失败不能输出 completed |
| QA 服务失联/长时间等待 | health + 截止时间 | 明确 QA 未完成，状态不能 PASS |
