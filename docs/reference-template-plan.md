## 假设与实现边界

- 延用本地 macOS / Python / FFmpeg / 当前网页环境，不新增外部 API 或依赖。
- 固定包装可从成片测量；拍摄机位和原始删句无法从成片反推。源素材只有横向分屏时保留双方；不会伪造多机位，也不将双人上下排列。
- 新模板采用自然提问/观点开场，不重复插播 cold，不添加白闪、悬念卡、结尾 CTA 或人为音效。
- 常驻两行标题、绿色关键词、低干扰白色字幕、黑绿底、单一中央画面窗口、可填写栏目/品牌及说话人资料。窗口约 x=0,y=510,w=1080,h=960；源画面等比容纳，不拉伸、不盲目裁脸。
- 输出时长 60–300 秒，选题目标 90–270 秒；容纳参考中 4 分 12 秒的完整论证。一般模板保持原有合同和样式。
- 姓名/身份由用户按字幕说话人 ID 确认；身份用于发言者说明，不假装是人脸识别结果。空白不显示。
- 同直播、模板及相同输入复用结果；修改资料产生独立历史任务，不覆盖旧片。模板信息必须参与缓存哈希。
