# 转换耗时记录验收（2026-10-14）

每次自动切片任务在 `web-run.json` 的 `timing` 中保存开始时间、结束时间、处理秒数和计时来源。新任务使用单调时钟计时，包含检查输入、选题、计划、渲染、质检和结果保存，不含排队、源视频转写与人工标注。失败也保存已耗时；查看已有成片不重新计时。

旧任务仅在最近一次管线有完整阶段时间时补录。时间为最早阶段开始到最后阶段结束（含阶段间隙），来源标记为 `pipeline_history`；不使用记录创建时间或更新时间推算。缺失数据展示“未记录”。补录不改变历史排序时间。

网页历史显示成片数量与耗时；详情另显示平均每条耗时和各阶段耗时。旧任务明确提示可能包含配置或成片复用，不能据此比较首次全流程性能。
