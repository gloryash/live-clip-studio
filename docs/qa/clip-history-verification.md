# 成片历史修复验收（2026-10-14）

## 已确认的原因

- 日常启动器使用端口 8788，之前验收用端口 8787；8788 旧后端对 `/api/clip-runs` 返回 404。
- 浏览器首页缓存旧版 `app.js`，资源加载来自缓存，只查询 health/jobs，没有查询切片接口。
- 重复保护仅检查 queued/running，completed/needs_review 会再次创建任务。

- 更新日常入口 8788 的本地服务；确认重启前无转写或关键帧任务正在执行。

- 为 completed/needs_review 增加后端结果复用；failed 仍允许重试。
- 在直播卡片标记成片数量，选择已有结果后显示“查看已有成片”。
