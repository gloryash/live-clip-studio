# 观点对谈 v2：以参考成片为标准迭代

## 已观察差异

对照用户在 9400 的任务 `4bb131f2-ce24-47bc-8229-777d09d5038e` 与下载目录三条参考：原预设竖屏全图缩小，中央主体过小；分屏未形成发言者主镜头；身份远离人物；标题居中且字号随长短变化明显；引号偏小偏中，点阵过暗。

## 假设与边界

- 延用本地 macOS、FFmpeg、Pillow 和已安装的 OpenCV；人脸检测只用于构图，不用于识别人名。
- 参考是拍摄好的多机位，测试源是手机录屏。可改善主体比例和包装，不能凭空恢复摄影机的背景、清晰度和机位。
- 单人大画面可据稳定人脸位置裁去空天花板和界面；小窗不作为主要人物。多人分屏若未确认出镜位置则保留双方；允许按说话人额外指定左/右，仅在检测到稳定左右两人时使用。
- 构图按连续源片段稳定，不每帧追脸；无法可靠检测则保留原画面。人脸和头部需留边，无法安全铺满时用同画面的柔和背景补边。
- 测试身份允许虚构，但演示资料明确标记；不覆盖用户旧成片。新版本单独保存历史，版本参与去重与渲染缓存。

## 执行与验收

1. 测量参考，保存相同尺度的参考/旧片对照图。产出：位置与比例表。
2. 改人物构图、标题、字幕、信息条、底板。产出：独立 v2 规则及构图日志；测试无裁脸、无上下双人排列、失败回退。
3. 用旧片相同选句渲染第一轮，分离视觉改动与选题差异。产出：相同时间点的前后对照，逐项评分。
4. 根据第一轮问题再调整并重渲染。产出：最终三条真实成片、抽帧和技术质检；人物呈现面积接近参考，标题与署名坐标对齐。
5. 网页检查、历史版本/去重测试、回归测试及独立 Git 提交。产出：9400 可查看新旧记录、测试与实测耗时。

对齐标准：1080×1920；主体窗口约 y=510–1470；标题左缘约 90、两行统一字号且不溢出；字幕在窗口底部；身份紧邻人物，栏目品牌固定；主要脸部完整、无无故上下排列、无周期性缩放。录屏原始质量差异在结论中保留说明。
